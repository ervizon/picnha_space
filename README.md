# 💕 Pincha Space - Date Planner & Memory Album

Sistem web modern dan estetik untuk merencanakan kencan impian bersama pasangan, mengatur jadwal, lokasi, agenda kegiatan (*"ngapain aja"*), serta mengabadikan foto dan kenangan manis setelah date selesai.

---

## ✨ Fitur Utama

1. **🗓️ Atur & Rencanakan Jadwal Date**:
   - **Judul & Tema Date** (misal: *Sunset Picnic, Rooftop Dinner, Cinema Date*).
   - **Tanggal & Jam Kencan** lengkap dengan hitung mundur (*countdown timer*) otomatis.
   - **Lokasi & Tempat Date**: Nama tempat dengan integrasi tombol langsung ke Google Maps.
   - **Dress Code & Warna Baju**: Inspirasi outfit kembaran / serasi.
   - **Catatan & Reminder Khusus**: Reservasi meja, barang yang harus dibawa, dll.

2. **📋 Rencana Kegiatan / Itinerary ("Ngapain Aja")**:
   - Timeline aktivitas dinamis (misal: `15:30 Jemput` ➔ `16:00 Ngopi santai` ➔ `18:00 Sunset` ➔ `19:30 Dinner`).
   - Checklist interaktif: Bisa dicentang langsung saat kegiatan sedang berlangsung.

3. **📸 Galeri Foto & Jurnal Kenangan (Habis Date)**:
   - Upload banyak foto hasil kencan sekaligus (*drag-and-drop* didukung).
   - Rating kencan bintang (1-5 ⭐).
   - Catatan kesan & cerita kencan (*highlight*).
   - Tampilan foto bergaya polaroid & galeri *lightbox* resolusi tinggi.
   - Status otomatis berubah menjadi *"Selesai & Berkesan"*.

4. **✨ Fitur Tampilan**:
   - **Hitung Mundur Real-time**: Banner countdown kencan terdekat berikutnya.
   - **Statistik Kencan**: Total kencan, jadwal mendatang, momen selesai, dan jumlah foto tersimpan.
   - **Filter & Pencarian**: Filter kategori (Semua, Akan Datang, Kenangan) dan kolom pencarian lokasi/kegiatan.

---

## 🚀 Cara Menjalankan

Aplikasi saat ini sudah aktif dan berjalan di komputer Anda pada:
👉 **`http://localhost:3000`**

### Jika ingin menjalankan ulang di kemudian hari:
1. Buka terminal di folder `C:\love`
2. Jalankan:
   ```bash
   npm start
   ```
3. Buka browser dan akses `http://localhost:3000`.
